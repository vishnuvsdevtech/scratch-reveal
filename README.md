# Scratch

**Live:** https://vishnuvsdevtech.github.io/scratch-reveal/

One thing worth the effort. A result hidden under foil. You scratch it yourself, and it happens exactly once per page.

**How:** The pointer erases with composite mode destination-out using soft concentric discs; every twelfth frame the alpha channel is sampled at 90px wide to measure how much is gone. Past 65% the rest wipes itself.

**What it is not:** Delight decays with repetition: the second scratch is manual labour, the tenth is a bug report.
